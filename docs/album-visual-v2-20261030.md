## 真实接口与行为

- 保留 Game.ui.photography.open({mode:'album'})；默认 / camera 均委托既有 Game.ui.photoEditor.open({photo?,onAlbum?,onSaved?})。增加的 photography.close() 仅关闭本模块持有的相册窗口并废弃其回调，不接管编辑器清理。
- 标签数量直接来自 sys.photography.list() / trash()，上限读取 maxPhotos，两组各 12 张。空册只引导既有相机，空回收夹不提供造照片动作；满册 / 满回收均有正文提示。
- 每次下载、改名、回收、恢复、永久删除及编辑入口都重读照片当前位置。移动 / 恢复容量交由系统拒绝，不自行增减列表、拍摄累计、任务、回忆或奖励。
- 相册详情提供下载 PNG、编辑装饰、改名、移入回收夹和返回。回收详情只提供查看、下载、恢复、永久删除和返回；恢复成功后进入活动相册详情，才出现改名 / 编辑。
- 永久删除有独立确认，明确不能恢复；默认焦点在「返回回收夹」，取消 / 关闭不调用 purge。失败留在确认页，可继续重试。
- 名称沿用原有的去控制字符、Unicode 码点截取逻辑，不使用 maxlength=30。名称为 1–30 码点，组合输入期间不截断、不提交，合成结束后规范化，emoji 不按 UTF-16 单元误算。配文作为 photo.decor.caption 单独展示，不调用装饰更新或用配文覆盖名字；0–30 码点配文的编辑和验证继续由既有编辑器 / 系统负责。
- 下载只调用 sys.photography.download(id)；底图、相框、贴纸和配文由原系统合成 PNG，不新增编码器，不把 JPEG 底图改后缀交付，不承诺旧照全部有高清底图。
- 系统返回 ok 后才给成功 toast / 声音并进入成功视图。false、Promise 拒绝和同步异常保留当前管理视图 / 表单值并重新启用操作。编辑器打开同步异常时优先保留原弹窗；若编辑器已经替换窗口再抛错，则重建原照片详情并保留错误正文。

## 生命周期与焦点

每次打开均创建独立会话，每张相册页持有独立 view；旧按钮、旧表单事件、读取结果、图片解码事件、下载反馈和编辑回调均验证当前所有权。图片重试还有独立 attempt，旧图片成功或失败不会改新图。列表读取支持同步值或 Promise，读取异常不伪装成空册。

state:replace 废弃当前会话并只关闭本模块持有的 handle，不能关闭其他模块窗口。编辑器继续使用自身的换档监听、AbortController、RAF、Observer、指针、HUD 和草稿清理；本批没有复制或更改这些内部逻辑。

真实编辑器采用先 handle.close()、再在同一调用栈执行 onAlbum / onSaved 的既有协议。本批在 modal:closed 后以微任务废弃未消费的 callback，合法同步返回仍可使用；关闭后的迟到 callback、重开或换档后的旧 callback 无效。

列表标签具备 tablist / tab / tabpanel 关系，支持左右方向键、Home / End。详情返回恢复对应照片入口焦点；改名聚焦输入；永久删除确认先聚焦取消。图片重试在隐藏原焦点按钮前同步移焦到对应相片入口 / 预览，读取重试先移焦所属 dialog，避免隐藏元素导致浏览器焦点回落背景。图片载入只替换图像容器，不重建操作和表单。

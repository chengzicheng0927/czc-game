准备完成后可使用已缓存入口离线玩，本机进度继续保存，联网再同步。若提示正在准备、出错或有等待更新的副本，按实际状态处理；更新等待旧小屋页面关闭后生效，不靠清除站点数据更新。离线目录版仍可直接双击，账号功能须回网站使用；定期保留JSON以应对浏览器回收缓存。

## SQLite备份与恢复

数据库在私有数据目录，不在静态webroot。`serve`在启动、每24小时及正常退出时生成一致性备份，保留最近7份；同磁盘备份不等于异机容灾。已有数据库可用以下不监听的命令手动备份：

```sh
node server/cli.cjs backup --data-dir .server-data
```

灾难恢复先停服务并保留当前数据库及WAL/SHM，在独立目录使用一致性备份恢复；对外启动前执行`rotate-epoch`撤销旧会话、同步基准与全部公开小屋（主人需重新公开），不能只回拨修订号或把旧WAL混回主库。完整命令、权限和恢复边界见[后端手册](../../server/README.md)。备份包含账号哈希、会话和完整小屋，不放进公开目录或项目文档。

## 备份与恢复

1. 打开「设置」→「导出存档」，把 JSON 文件保留到常用备份目录。
2. 可在「回忆」导出 Markdown 回忆录；回忆录只用于阅读。
3. 在目标浏览器或游戏目录中打开游戏，进入设置并选择「导入存档」。
4. 选择JSON文件，确认恢复后检查金币、房间、居民、主线/已读故事/成就/每日宝箱、彩虹碎片、相册/回收夹小图与装饰、图鉴与套装徽章、像素作品/挂墙/墙纸、礼盒免费日期和最近奖励、四款小游戏记录、花园库存，以及家具深度、衣装/搭配盒、外观、前院摆放和节日礼物；也检查居民当天心愿、好感与已经领取的好友礼物。
5. 导入失败应保留原进度。检查是否选择了正确版本的 JSON，勿反复清空浏览器数据。

JSON 包含完整持久进度；Markdown 仅是可阅读的概况和事件回忆。小游戏局内的棋盘、倒计时、选牌及暂停状态不保存，刷新或关闭页面会结束这次局内状态；已经结算的成绩、奖励和每日次数可恢复。离线花园按种植与浇水时间戳继续生长，重新打开后查看花圃即可，成熟作物需要主动收获。

同版本旧档缺少新游戏记录或花圃时会自动补齐；已存在的种子库存不会再次赠送。音频升级会保留静音和较低音量，重置旧声线选择与旧自动朗读偏好，不影响金币、房间或居民进度。导入前仍建议备份当前 JSON。

旧落地家具没有 depth 时会补成75%，canonical x/y不因投影而改写。旧空衣橱只补固定五件基础服饰，旧外观补默认拥有权；重复读档不会因此发币。已领节日礼物按节日年份记录，刷新或换回旧画面日期不应再次领取同一份。调试日历、当前预览中的未购买外观、相机和拖动状态不属于完整进度。

旧17条任务按ID保留已有奖励和领取记录；新35条主线从首个未领任务补位，旧章节不倒退，已领项不能再次领奖。缺少累计蛋糕数据的旧档，只能从最高订单和当日局数迁移可确认的历史下限，后续真实完成的蛋糕局才继续累计局数与订单。相册小图写入JSON；当前页面最近一张的大底图、派对动画和当前阅读句子不保存。

## 朗读与声音排查

1. 「听一听」直接点击即可使用，没有自动播报，也不需要在设置里先打开朗读开关。再次点击会停止，关闭对话也会停止。
2. 进入「设置」的中文声线选择器，先试听自动选择，再试听其它常规中文声线。增强/自然声线优先；Eddy、Flo、Grandma 等角色效果声线不出现在列表中。
3. 如果提示没有本机中文声线，在设备系统的语音或辅助功能设置中安装常规中文朗读声线，再重新打开游戏。列表由浏览器读取，是否提供增强声线取决于设备和浏览器。
4. 如果完全没有声音，检查游戏右上角是否静音、设置里的音量以及系统输出音量；先点击页面解锁浏览器音频。切到后台会停止朗读并淡出音乐，回到页面后可重新点击「听一听」。

只朗读明确台词或说明正文，不读取整张菜单和按钮文字。当前是本机语音合成，没有真人录音；若仅安装了基础声线，调整语速和筛选声线也不能保证真人质感。游戏不会为朗读调用在线语音服务。

## 室内 2.5D 摆放步骤

1. 在「装饰」选择当前房间和背包家具。室内物品选中后面板收起，相机会聚焦该房间，再点击房间落位；保留原生拖放入口。
2. 拖动已摆好的落地家具，向上靠里、向下靠前；画面随深度统一缩放，抓点应保持在指针下。拖动不会把人物改成3D模型。
3. 选中地面家具后，用「靠里／靠前」滑块精调。松开或结束一次键盘调整才保存为一次移动，控件保持焦点。0%和100%分别对应地板后、前沿，墙面和吊顶没有该滑块。
4. 台灯、花瓶等小物靠近桌面时吸附；父家具移动、改变深度或收起时，台面物品一起处理。深度决定实际前后位置，「向上一层／向下一层」用于同深度的层级微调，地毯保持最底。
5. 落点不满意可重新拖动或使用「撤销」。如果房间太小，双击房间或重新选择该房间后再摆；返回全景使用缩放/适配按钮。

排查投影错位时，分别核对保存的canonical坐标与画面的roomSpace结果；不要把投影后的屏幕x/y写回存档。非floor传depth应被拒绝，台面物品通过父变换定位，不给子物单独新增depth。

## 昼夜、天气与节日

- 设置选择真实昼夜、永远白天或永远夜晚。真实时间6–18白天、18–20黄昏、20–6夜晚；夜里应看到深蓝星月、暖光和居民休息。减少动态偏好会降低场景频率并让天气粒子静止。
- 天气按本地日期与季节稳定生成，刷新不会重新抽取；雨日15点后转晴，20点前且非固定夜景时可见彩虹。冬雪、春樱、秋叶是视觉效果，不影响作物存活。
- 从节日入口查看祝福、限定家具和礼物；领取后礼物进入背包。同一年同一节日不可重复领，居民生日按居民分别记录。
- 调试入口 `?debug=1` 可预览日期、小时、天气与节日；使用「恢复真实时间与天气」清除。调试覆盖只在页面runtime中，换档也会清除，但测试中正式领取的礼物和购买仍会保存，验收前先备份。

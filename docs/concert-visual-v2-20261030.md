## UI 与规则委托

故事正文和标题全文、三步名称、每段 notes 都读取 `data.concert`。入场为 verse 0，两次主动 advance 到第三段，再主动 finish；重听、朗读和绘制均不推进。没有计时、评分或声音结束回调。

所有资格和演出动作仍由 `sys.concert.status/begin/advance/finish/cancel` 决定。省略 roomId 仍委托系统选择首间；明确指定但已失效、null 或非字符串房间不会改投另一间。缺房/缺客显示系统原因，资格恢复后可主动入场；指定房失效明确说明关闭后从当前音乐室重新进入。

首次 finish 仍由原系统以 `persist:true` 保存 concerts=1 与一条包含本场姓名的回忆，保存后才发 `concert:finished`。本 UI 不写存档、不增奖励。重演不重复保存回忆/凭据或发布完成事件。拒写保留第三段与原 sessionId，主按钮可直接重试。明确会话失效则回到重新入场；提交后异常只提示结果未确认和核对路径，不据 completed 值伪造成功或回滚已存记录。

舞台背景为本模块 Canvas 木纹、海风帷幕与纸音符；每位真实入住来宾使用原 `G.render.drawCharacter(canvas, id)`。名牌为可换行 DOM 文本。桌面 4 人四列、较多朋友六列；手机最多四列，12 人三行。帷幕限制在两侧约 12%，人物与名牌留 16% 内侧安全边距。头像失败时保留姓名、故事和动作并提示插图不可用。

故事和三步进度处于可滚动区，底部主动作、保存反馈及主动重听/朗读分开固定；关闭沿原 modal，目标至少 48px。隐藏或禁用前捕获焦点，恢复使用 preventScroll；推进、拒写和隐藏原重入/故事按钮均有焦点去向。正文、名字、标题与错误不使用省略、行数截断或不换行限制。矮窗口继续压缩故事滚动区，减少动态时取消本批动画/过渡。

仅入场、换段、阵容变化或必要状态排单次 RAF；来宾不变时不重复调用角色绘图。主动旋律沿 `audio.play('concert_' + verse)`，主动故事沿 `ui.speak(当前正文, 按钮)`；静音时仍能完成。换段/收起使用既有 stopSpeech/stopConcert，没有新增音频引擎、策略、录音或网络。

关闭/换档后解除本批按钮与 bus 监听、取消待绘 RAF、清空舞台和角色 Canvas 并将尺寸归零。无临时 holder 或常驻 loop。旧节点/迟到帧有所属场次检查；每次系统调用返回后再核对 UI 是否仍有效。若提交 busy 期间关闭导致第一次 cancel 被拒绝，finally 会在系统返回后仅补取消捕获的旧 sessionId，不取消新弹窗的场次。

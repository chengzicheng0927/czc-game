## 修复目标与边界

用户反馈花园、院子消失，希望主岛更大。恢复后的家园同一主岛容纳屋体、屋前可布置庭院和右侧真实花圃，继续使用原软陶人物、圆润环境资产、莓红公共外壳与奶油图卡。庭院保留“庭院背包／庭院小铺／已经摆好”专用面板；自由画墙工具仍属于高级玩法。

`BuildingDocument`的schema2墙段、开口和家具继续是空间权威。庭院家具的操作使用同一建筑命令、库存事务与撤销记录，不重新启用旧`house.yard.items`写链。换房仅替换屋体，庭院保留与旧回包物品的恢复边界见[房型规则](house-blueprints.md)。种植花园仍由既有`garden`规则和真实存档驱动，不新增示例作物或赠送物品。

## 布局尺寸

`src/content/home-landscape.ts`的`createHomeLandscapeLayout(house, placed)`是纯布局计算，返回屋体边界、庭院、花圃区和主岛中心及半径，不修改存档或建筑几何。

| 区域 | 当前源码尺寸与定位 |
| --- | --- |
| 主岛 | 半径至少9.5米，即直径至少19米；按屋体、院子、花圃边界继续扩大，兼顾已有家具位置。9.5米不是直径或镜头距离。 |
| 庭院 | 位于屋前+Z方向，与屋体前边缘留0.55米间距；深3.5米，宽按屋体宽度加1米计算并限制在6.6–9.2米。 |
| 花圃区 | 位于屋体右侧，宽4.8米、深5.1米，缩放0.78；与庭院单独留位，9块花圃不挤占庭院操作区。 |

主岛树木、围栏、长椅、邮箱、花团、踏石和茶桌等固定环境资产继续作为场景装饰，不冒充已拥有家具、奖励或背包物品。已有实际家具不得因扩岛被自动移动、消失或重新发放。庭院新摆放和移动按家具旋转后的整体范围核对庭院边界，给屋体与花圃留出通路。

## 运行接口

| 接口 | 职责 |
| --- | --- |
| `createHomeLandscapeLayout(house, placed)` | 计算同岛分区和容纳范围，返回`house`、`yard`、`garden`和`island`；不持有引擎、DOM、规则或存档。 |
| `BuildingRenderer.setHomeGarden(snapshot \| null)` | 接收真实状态、`gardenStatuses`和选中地块；更新家园右侧花圃。只读展示；房型预览与参观时不混入本人花园。 |
| `BuildingRenderer.yardBounds()` | 返回庭院米制边界，供摆放和移动校验。 |
| `BuildingRenderer.focusYard()` | 定位屋前院景，不切换独立场景。 |
| `BuildingRenderer.focusGarden()` | 近看同一主岛上的真实花圃；打开园艺面板也不替换房子和院子。 |
| `BuildingRenderer.setSurface('garden', snapshot)` | 保留兼容接口，当前默认园艺流程不调用独立园区。 |
| `G.buildingEditor.yardSnapshot()` | 只读返回`unlocked`、`unlockLv`、庭院`floorId`及真实`items`，不从旧归档补物品。 |
| `G.buildingEditor.openYard(options)` | 进入庭院；`{panel:false}`仅准备场景以供面板调用，避免面板递归。首次进入才定位，普通刷新保持操作与镜头。未解锁只查看，不创建庭院层或修改布置。 |
| `G.buildingEditor.beginPlacement(id, null)` | 核验庭院等级和真实库存，选择庭院地面；落地通过新建筑命令扣库存。 |
| `G.buildingEditor.focusFurniture(uid)` / `removeYard(uid)` | 在原院景选中、移动、转向或收回真实实体；庭院物品保持庭院专用面板。 |
| `G.buildingEditor.undo({redo})` | 撤销或重做建筑和对应库存差值；不回滚已经支付的钱包或永久内容拥有权。 |
| `G.sys.economy.buy(id, expectedPrice)` | 小铺使用既有购买事务和真实价格，失败不改库存；加工和奖励物不冒充可购买商品。 |

庭院等级仍为Lv11，最多120件，库存来自真实`inventory`。未解锁可查看背包、小铺图卡与原有院景，购买、摆放和调整按钮明确禁用。本批未恢复连续铺路或自动补购，界面不显示这些尚未接入的操作。

## 真实花圃与入口

种植容量继续读取`G.data.gardenConfig`与`G.sys.garden.capacity()`：Lv6开放6块，Lv14扩为9块。首页花圃读取`G.sys.garden.status(index)`和既有`describeGarden`内容，呈现真实作物品种、阶段、浇水需求和成熟状态。未解锁时显示开放等级，不生成可种植的示例地块，也不扣种子或加收获。

房子成长书提供“布置我的院子”和“照顾花园”；庭院页也能直接去花园或回房型书。首页花圃命中继续调用`G.ui.garden.openPlot(index)`，空地进入原播种窗、缺水进入原浇水、成熟进入原收获；花园招牌打开原花园页。底部“花园”入口近看同一主岛地块，原种子铺、花果加工和收获篮继续由原面板与系统处理。

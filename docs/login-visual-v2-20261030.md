## 生命周期与可访问性

每次内容重建都会使旧会话失效。按钮执行须同时满足当前会话、档案代次、可见宿主、连接状态、非busy与非disabled。关闭后仍挂在抽屉DOM中的旧按钮也不能调用claim；换档关闭旧弹窗，清提示日期、timer、反馈与绘图。

绘图只按需安排单次RAF；重读/重建/关闭会取消旧RAF，清空并归零旧Canvas。迟到回调再次核对会话，不能绘旧家具或把旧结果反馈到新档。公开content被通用弹窗承载的关闭清理也已覆盖。

动作区域原位更新。失败优先保留领取按钮焦点，成功后焦点到回执；不可聚焦按钮回退到状态/回执，使用preventScroll。抽屉重建时传递焦点键及滚动位置，弹窗使用自身modal-body滚动宿主。状态区保留role=status、polite和atomic，失败回执使用role=alert。原弹窗焦点陷阱/Escape由共享宿主继续负责。

手机DOM先主卡后七格；桌面CSS将七格排在主卡前。长礼物名、日期、轮次、原因允许完整换行，无省略号/行数裁切；操作最小48px。装饰礼物使用CSS静态层次，家具保留真实缩略图；没有持续动画。暖纸正文/辅助文字、薄荷状态、主按钮和错误文字的声明色对比度分别计算约为6.97、5.23、6.23、4.98、7.25，属于CSS色值计算，不能代替实际整页测量。

自动提示保持原条件：引导done、可见页、无抽屉/弹窗、当日未提示且可领。modal:closed仍只安排一个700ms检查；重复关闭替换原timer。没有新增轮询、通知、自动领取或提醒策略。换档关闭弹窗产生的关闭事件timer也会被清除。

# 房型与室内美术制作规格

日期：2026-11-09。当前交付是[12张美术设定源图](../assets/art/house-room-v1/README.md)与以下制作规格，尚未制作或接入新的三维模型。以原人物的圆润软陶质感、奶油/莓红公共界面为基准。

## 先完成的内容范围

先制作五档外观与一间可布置卧室，覆盖“选房 → 看外观 → 进屋 → 摆家具”样板。整栋选择仍是孩子的主流程；自由画墙、门窗留在高级玩法。原人物、面板、购买条件、拥有权和朋友不因美术替换而重做。

| 资产 | 现有交付 | 后续制作与验收缺口 |
|---|---|---|
| 五档房屋 | 5张外观设定PNG | 按真实蓝图制作墙、檐、屋顶和塔体，侧/后视及剖面验收 |
| 卧室相机 | 1张双视角概念板及下列参数 | 同场景相机与屋顶/遮挡墙联动、切层和手机视口验证 |
| 床/柜/灯/衣柜 | 4张独立造型参考PNG | 四面/顶部网格、米制尺寸、支点、拾取范围、材质；图卡透明边缘亦未定稿 |
| 墙地 | 2张颜色贴图候选 | 重复铺贴、UV比例、接缝与动态光照检查；法线/粗糙度未提供 |
| 真门窗 | 现有逻辑ID `door_wood` / `win_square` | 新风格门框、窗框、窗台及侧/背面模块；与真实墙洞同步 |
| 银杏/圣诞树/云 | 上一批PNG造型参考 | 可旋转近景树和体积云的网格/材质；远景贴片另验透明排序 |
| 其它房间与家具 | 保留现有内容 | 本批未覆盖全目录；样板通过后再按主题扩充 |

PNG设定图不能当可旋转房屋模型，透明通道也不等于干净图卡。床的宽光晕在一次背景清理后仍存在，修正版未选用；原图仅供造型参考。另三件柜/灯边缘仍有局部白边和彩边。双视角板家具大致同位，但左墙窗户画法不一致；下列真实数据为制作依据。

墙高2.35米，层差2.65米。现有蓝图未定义楼梯；塔体、星饰、檐口不凭空新增可住空间。庭院是独立地面，不计入层数、房间数或朋友容量；替换房屋外观不移动庭院及花圃。

屋顶应是与外轮廓一致的连续玩具屋面，保留软边、厚檐与清晰窗户。进入房间时收起屋顶；不能把外观设定图整张贴上，或把屋顶拆成每间房一块的厚积木。墙体必须保留真实门窗洞，装饰家具 `window_basic` 不能代替 `win_square` 开口。

## 同一房间的三种相机用途

以下为拟采用的规格，非本轮已修改的运行代码。相机与剖面是临时显示状态，不改建筑文档、库存或存档。

| 模式 | 目的 | 画面与操作要求 |
|---|---|---|
| 看我的家 | 主岛欣赏外观 | 显示完整屋顶、庭院和真实花圃；选择房型时预览整体轮廓 |
| 看房间 | 看家具造型、人物与装饰 | 当前楼层/房间的三分之四剖面，屋顶隐藏；近侧遮挡墙收起或变淡 |
| 摆家具 | 判断占地、落点和通道 | 同一房间近垂直俯视，隐藏屋顶与遮挡；移动/旋转/收回、撤销重做仍操作同一实体 |

斜视建议沿 `+X/+Z` 观察，Babylon相机 `alpha ≈ 65°`、`beta ≈ 0.78rad`（距垂直约45°），目标位于房间中心、当前楼面以上0.6–0.9米。房间约占扣除面板后可用画面的70–80%，留出人物和选中轮廓。

俯视建议 `alpha = 90°`、`beta = 0.04rad`（约87.7°高于地面）；优先正交投影以保持占地清楚。当前已有 `topView` 只转动相机，不自动收屋顶，也不切换正交投影，接入时须明确补齐。两种相机共用相同地面拾取、家具变换与房间范围，不重新生成一套房间。网格只作摆放辅助，不烘进墙地贴图。

高衣柜靠后/侧墙仍须可见、可选。选中轮廓和半透明摆放预览由运行渲染生成，不能烘在素材里。切换视角、楼层或面板后不丢选中实体；两层房型要有明确楼层选择，不以想象中的楼梯代替入口。

手机应按抽屉占用后的实际空间重新取景，保留点击和旋转手柄的空间；相机不能仅沿用桌面距离。倾斜/俯视切换按钮继续沿用现有软陶/莓红工具样式，不另做工业编辑器外壳。

## 卧室样板尺寸

样板采用 `starter` 后侧房间：`x ∈ [-2.6, 2.6]`、`z ∈ [-2.6, 0]`，地面5.2 × 2.6米，前侧内部门居中。后墙中间一窗、左右侧墙各一窗，共三窗；制作时读取真实开口位置，不能照抄概念图漏掉的一扇。

家具尺寸沿用真实内容目录，顺序为宽/高/深，单位米。支点取底部中心，`y` 相对本层楼面；下表是样板布置建议，不是本轮写入的用户存档。

| 内容ID | 宽 / 高 / 深 | 建议中心 `x,z` | 楼面以上 `y` |
|---|---|---|---|
| `bed_basic` | 1.45 / 0.72 / 2.05 | -1.5, -1.3，长轴沿Z | 0 |
| `nightstand_basic` | 0.52 / 0.58 / 0.48 | -0.4, -2.2 | 0 |
| `desk_lamp_basic` | 0.25 / 0.42 / 0.25 | -0.4, -2.2 | 0.58，置于柜面 |
| `wardrobe_basic` | 1.15 / 2.05 / 0.62 | 1.8, -2.25 | 0 |

柜、灯使用独立实体；不由图片虚构柜门动画、自动跟随或灯开关。具体摆放仍按现有规则和真实库存执行。

## 三维接入时的验证门槛

1. 先在单间样板做出四件真实家具与门窗：旋转看正、侧、背、顶，检查支点、比例、拾取和衣柜遮挡；两种相机保持同一实体和开口。
2. 检查五档外观的连续屋面、入口和各面窗户，星光城堡切层后保持正确层高与六个真实房间。
3. 实际摆放、移动、旋转、收回、撤销重做、保存刷新；对比实体ID、库存、朋友住址、庭院位置和作物时间线。
4. 为新静态文件补齐发布清单、MIME和离线缓存。当前发布收集器仅收JS/CSS，复制PNG进仓库不表示运行发布包已能加载。
5. 在原4173真实浏览器检查桌面与窄屏的图像、点击、遮挡、帧率和离线可用性，再标记“已接入”。本轮只有原图/通道/文档检查，不冒充这些运行验收。

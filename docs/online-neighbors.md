## 范围与在线含义

在线指已经主动加入公开联机小屋、尚未离开/过期的成员，不枚举登录账号或私人小屋。列表以小屋分组展示正在这里玩的公开称呼、人数和屋主是否在场；在线区在普通公开小屋之前。在线区保留自己的小屋，避免漏掉来自己家玩的朋友；普通分页列表继续排除本人公开记录并去重在线小屋。

有空位的在线小屋提供「去串门聊天」，打开同一公开参观入口的精确`#join`片段；已登录者自动主动加入一次，沿用本人当前已经公开的串门称呼，其次本人公开小屋展示昵称，最后通用「小小建筑师」。不自动公开登录名或账号昵称。游客仍只读并显示登录入口。普通参观、未知片段、直接打开网址不自动加入。满员提供查看入口，最终可否加入由服务器当时容量判断。

## API

新增公开`GET basePath/api/v1/neighbors/online`，沿用协议1/build、同源和no-store门禁，匿名可读。返回`{houses:[{id,title,displayName,roomCount,updatedAt,online:{count,hostOnline,displayNames}}]}`，最多64屋、每屋1–8个实际加入称呼。服务器先清理TTL/失效会话/撤下或更新的小屋，再生成纯摘要；不续期任何成员，不返回账号ID、用户名、peerID、头像、聊天或位置。排序：有空位优先，其次屋主在场、人数降序、公开updatedAt/id降序。满员只影响直接加入按钮，不删除房屋。

旧`GET /neighbors?cursor=...`保持返回/游标合同不变，作为普通公开列表分页；在线结果单独全量有界，不把变化频繁的在线排序塞进旧游标。

`GET /live/me`仅认证成功的本人响应新增`joinDisplayName`，来源：当前实际在线成员已经公开的称呼 → 本人publications.display_name → 通用称呼。匿名仍只返回`{authenticated:false}`。lookup不续期在线，不枚举别的账号。

## 客户端

邻居列表打开、处于列表页签且文档可见时，每10秒刷新在线区；关闭、后台或离页停止，返回后立即刷新。请求跨账号/关闭/页签变化以generation拒绝迟到响应。不重复重建发布表单，不因定时刷新丢掉输入或链接焦点。刷新失败保留有用的上次记录，但明确过期，旧绿在线标识和自动加入动作撤销，提供刷新恢复；成功空结果显示暂时没人串门。

`Game.cloud.requestPublic`仅扩展`/neighbors/online`白名单，仍credentials:omit，不调用私人云存档初始化/租约。

`Game.live.quickJoin(houseId)`使用与手动join相同的fresh `/me`身份确认，在同一次Cookie绑定握手内选择安全称呼，再POST join；不把上次probe获得的另一孩子称呼传给新Cookie。未知/非法推荐称呼回退通用称呼。普通`join(houseId,name)`行为不变，403/满员/网络失败不自动重复加入。

visit在公开快照成功加载后读取并消费精确`#join`，传`quickJoin:true`给liveRoom.mount；只在文档可见且认证成功时尝试一次。游客不保留待执行的自动加入意图；失败、退出、刷新或BFCache返回不会再次偷偷加入。消费片段不改其他路径/查询，不初始化主人进度。已有账号、公开/撤下、实时聊天/走动、离线/JSON合同均保持。

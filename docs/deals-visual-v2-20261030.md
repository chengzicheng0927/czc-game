## 数据与购买合约

目录直接读取 `sys.deals.status()` 及其真实 list 结果；点击另读 `priceFor(id)`。UI 不复制候选池、FNV/xorshift 抽样或折价算法，也没有 362 常量。完整正整数 coin 普通家具池、庭院、日期确定六件、等级/拥有/收藏不筛池以及 `ceil(price*4/5)` 仍由原系统负责。

卡片使用真实 definition、主题、原价/折后价、当前库存、解锁等级和系统完整原因；满 9999 明示同款上限。未引入每日单件限购、倒计时、刷新轮询或抢购机制。同日购买、升级与换档不改目录。增加「重新读取目录」用于手动恢复状态与核对价格，不写进度。

购买只委托 `economy.buy(id, expectedPrice)`，沿用原系统 busy 与 `store.update(..., {persist:true})`，钱包、库存、collection、购买统计、经验、回忆仍同次提交。UI 不写存档、不改普通货架 priceFor 行为、不扩大持久化保证。明确成功返回后才播 success 和 toast；拒写、异常及未知返回均无成功音效或 toast，重新读取真实资格后可重试。

点击前核对渲染日期、最新日期和报价。日期或价格改变时先更新目录并明确提示「这次没有购买」，该次不调用 economy.buy。不会静默按新价格购买旧卡。

## 生命周期与交互

- 同目录局部更新价格、库存、预算和资格；购买本身不主动调用共享 ui.refresh，不重绘六件 Canvas。
- 模块级与 session busy 共同防止同步事件重入。独立 archive 代次使换档旧按钮、反馈与 RAF 失效；不使用每次 update 都变化的 state 对象身份判断换档。
- content 宿主刷新时销毁旧 session，并继承同档案的待恢复焦点与 `#panel-body.scrollTop`。同步购买事件重建宿主时只继承位置，不转发旧页面的迟到成功反馈。
- 单次 RAF 完成按需绘图和焦点恢复；仍可购买时回同款按钮，禁用或目录已无此款时落到可读反馈。用户在 RAF 前主动移到其它控件时不抢焦点。焦点使用 preventScroll。
- owns 检查当前 session、档案代次、连接、隐藏祖先及 shop 宿主。MutationObserver 在移除/隐藏时清理；panel:change、modal:closed、state:replace 也有失效处理。没有持续 RAF 或轮询。
- Canvas 保留 `G.render.drawThumbnail(canvas, id)` 真实家具绘制调用。采用本页专属 `data-deal-furniture`，避免共享 thumbnails 扫描 `data-furniture` 后追加不可控重复绘制。
- 保留 `ui.furnitureRarity.decorate` 装饰。销毁取消本批 RAF、断开观察器、禁用旧按钮、移除稀有度徽章并清零六个 Canvas 像素缓冲；迟到帧检查 ownership。绘图异常仅降级插图，不阻断文字和购买。

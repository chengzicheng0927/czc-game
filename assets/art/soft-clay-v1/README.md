## 接入边界

- 当前场景支持自由转动及近顶视。树的透明PNG可用于图卡或明确的远景贴片，不能当作能绕到背面查看的完整三维树。近景树需要真实枝干和叶簇网格、材质与碰撞/拾取边界。
- 云PNG可用于远景分层；主岛下托云和近景云仍需真实体积。城堡需要匹配真实墙段、门窗、剖面与空间的模块化三维资产，不能用整张设定图遮住房屋。
- 图片已经烘焙光影，不是可平铺的墙材、法线贴图或完整PBR材质，接入前须按用途制作配套资源。
- 当前发布程序仅收集JS/CSS。这批PNG尚不在release和离线资源清单中；正式使用须补资源manifest、MIME和缓存，或在构建时明确内嵌。不要直接复制后声称已在游戏生效。
- 后续美术按此方向统一比例、光照与材质，保留原人物形象和莓红面板。已有账号、存档、花园与庭院规则不因美术替换重置。

本批只验证美术原图，未修改运行代码、构建新release、操作浏览器存档或重复执行玩法测试。

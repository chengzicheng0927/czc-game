# 棉花糖小屋 · 立体原型范围与功能覆盖

日期：2026-10-30。用途：审核视觉方向、页面组织与交互流程。

这里的「现有」指当前游戏源码和说明中已实现的能力，不代表新原型已连接真实服务器。原型中的邻居、在线状态、聊天、队伍、奖励和账号均为演示数据；审核行为不应修改正式小屋、真实账号或云存档。敲门、匿名路过、主页面接待和组队协作的状态分别注明，不能把设计稿称为已上线功能。

## 本次新增概念

这些是供用户审核的扩展玩法；不表示已接通真实多人游戏服务。

| 概念 | 页面 | 最小可审核闭环 |
| --- | --- | --- |
| 公共云朵广场 | `plaza` | 进入广场→看公告牌→选活动→进入对应页面 |
| 2–4 人组队任务 | `quests` / `team` | 看任务→创建队伍→选择分工→准备→队长出发 |
| 星糖采集与云桥修复 | `coop` | 收集→贡献材料→团队进度→修桥→到达终点→结算 |
| 双人/多人共同烘焙 | `bakery` | 一人备料→一人搅拌→共同装饰→出餐→共享结果 |
| 共同浇水或花园周任务 | `garden` / `team` | 接周任务→选择花圃→贡献动作→共同进度→奖励展示 |
| 邻居一起喝茶、表情互动、双人合照 | `visit` / `album` | 主动互动→角色/气泡反馈→拍照→回忆册 |
| 星糖夜游会 / 夜间集体庆典 | `events` | 接活动→组队完成目标→全员站台→纪念合照 |
| 团队结算与再来一局 | `result` | 显示全员完成、分工与奖励示意→再玩/回家/合照 |

完整审核路线：**家园→云海→邻居门前→路过或敲门→会客→组队→合作小游戏→结算→合照→回家布置纪念物**。新增纪念物、共享奖励、组队进度均只在原型演示层变化。

## 官方游戏参考与转化方式

- **《集合啦！动物森友会》**：官方介绍包含朋友互访、动物邻居、喝咖啡、梦境只读探索和装修作品展示。借鉴的是「先看自己的家，再走向朋友的家」的空间连续性、角色尺度和轻社交仪式；本原型独立设计美术与文案。[任天堂：Share your community](https://animalcrossing.nintendo.com/new-horizons/share/?cid=N1043-01%3Ach%3Dpdpd)、[任天堂：与朋友同玩的建议](https://www.nintendo.com/en-gb/News/2020/May/Top-tips-for-playing-Animal-Crossing-New-Horizons-with-friends-1783708.html)
- **《Sky 光·遇》**：官方将其描述为安静的多人解谜冒险，强调七个区域的探索与玩家共同回忆。转化为云海远近层次、柔光、空中路径、协作点亮与活动后的纪念合照，而不是复制角色或场景。[Sky 官方首页](https://www.thatskygame.com/)
- **《Palia》**：官方介绍列明共同采集和朋友共同料理；Home Tours 可参观玩家主动提交的家园并给出表情反应。转化为「各自贡献小动作→共同得到完整成品」、家园参观反应和装饰灵感回流。[Palia：Gameplay First Look](https://palia.com/news/gpfl-highlights)、[Palia：Home Tours 官方说明](https://palia.com/news/patch-182)

视觉转化建议：以有厚度的浮岛、3/4 斜视角房屋、暖窗、接触阴影、前景植物、远景云岛和可读人物构成场景；UI 采用少量悬浮 HUD、糖霜按钮与抽屉。22 页通过不同场景和操作方式区分，不应全部变成同一种内容卡片网格。

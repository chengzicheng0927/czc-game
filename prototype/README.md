# 棉花糖小屋 · 云岛生活设计原型 V2

这是一套供审核的独立原型，包含 22 个页面。以原生 WebGL 绘制立体软陶云岛、房屋、剖面房间、花园、人物、邻居岛屿和天文台；DOM 负责游戏 HUD、面板与交互。不使用第三方运行库、CDN、外部图片、字体或音频。

## 打开与审核

- 当前本机预览：[打开原型](http://127.0.0.1:4173/prototype/#home)。同一服务的 `/` 继续打开原游戏。
- 离线可双击本目录 `index.html`；保留同目录的 `style.css`、`characters.js`、`scene.js` 和 `app.js`。本轮实际浏览器验证使用 HTTP，未单独验收 file 入口。
- 顶部选择器、前后页按钮或「全部页面」可浏览 22 屏。
- 拖动场景旋转，滚轮或镜头按钮缩放；在家园、串门与组队场景可点地面让人物移动。方向键 / WASD 也能移动，输入框与画板操作不受影响。
- 「审核笔记」按页记录意见，可导出 JSON。笔记、画作、照片和示例进度仅留在当前页面内存；刷新会清空，离开前请导出需要的内容。

## 页面与范围

开场、家园、建造装饰、云海邻里、串门、广场、组队大厅、合作关卡、甜品工坊、结算、游乐场、花园、商店、居民、换装、成长、相册、图鉴、画板、天文台、活动、设置。

[逐项功能覆盖矩阵与游戏官方参考](coverage.md)区分：

- **现有功能**：建造/装饰/外观/前院、居民与好感、四款小游戏、花园加工、换装、家具与特惠礼盒、主线每日成就、相册图鉴画板、生日节日合奏观星、七日心意、账号云档与备份等，使用代表性样本和状态演示新界面。
- **已在本地实现的新逻辑**：敲门同意、匿名路过、主页面同屋、八套人物预设与接待控制；原型按既有字段重做视觉。
- **新增概念**：云朵广场、2–4 人组队、星糖采集/搭桥/点灯、合作烘焙、团队奖励与纪念合照。

原型中的邻居、聊天、队友、账号、在线状态、库存与奖励均为示例；不连接账号/公开小屋/联机 API，不读取或写入正式游戏存档。页面中已有功能的覆盖不是重新实现全部正式规则或全部 407 件家具。布局深度、头像细分、天气等部分控件用于审核状态与流程；相册导出当前为场景底图，贴纸装饰的完整导出仍以正式游戏为准。

## 推荐审核路线

家园 → 云海邻里 → 选邻居 → 敲门 → 演示主人请进 → 本地示例聊天 → 一起做任务 → 准备 → 出发 → 收三颗星糖 → 修桥 → 点灯 → 领奖 → 合照 → 编辑相框与配文。

也可以单独试：家具试摆换色、商店购买、免费礼盒、花园收获加工、三步蛋糕制作、翻牌配对、16×16 像素画、照片回收恢复、设置里的账号/云档冲突与备份流程。

## 本机预览实现

`preview.cjs` 是本次独立审核的本机启动入口：调用已有游戏 CLI，并在同一个 4173 服务上仅开放原型的六个白名单文件。没有修改 `server/` 源码，也没有激活新正式版本或部署线上。

当 4173 未被占用时，可在游戏项目目录运行：

```sh
node prototype/preview.cjs
```

已有服务运行时先确认实际监听，不另起端口或重复启动。该入口沿用原 `.server-data`；私人数据不作为静态目录公开。

## 已执行验证

- `node --check` 检查 `app.js`、`scene.js`、`preview.cjs`。
- 1280×720 下逐页打开全部 22 屏；WebGL 实际渲染，无页面横向溢出、无浏览器错误。
- 390×844 下查看主场景及七个重点页面，无横向溢出；保留页面外层滚动与固定底部导航。
- 实际点击串门请进/聊天、队伍准备、采集→搭桥→点灯→结算、奖励防重复、合照配文与审核笔记。
- 修正三处独立复核发现：画室标题遮挡、结算夜景文字、领奖后游戏根容器意外滚动。领奖后 `main.scrollTop=0`，HUD 与 dock 保持原位。
- 截图和浏览器记录位于 `review/`。机械检测因 HTML parser 不可用降为 regex，不能当作对比度或完整无障碍验收。

未执行正式游戏全量回归、真实多人/跨设备、手机真机触控与性能测试；本次未改正式游戏源码或发布版本。
